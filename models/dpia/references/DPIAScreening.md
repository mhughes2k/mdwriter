# Section 1
1.		Will the project/policy/procurement involve processing personal data, i.e. data which relates to an identified or identifiable individual?
This definition can include IP address, cookies or other facts that could directly or indirectly identify an individual.  
NB for procurement/purchasing exercises this relates to the goods/services being purchased, not any information shared as part of the tender process, e.g. CVs/contact details from tendering organisations etc. 		

If ‘Yes’: answer Section 2.
If ‘No’: no personal data is involved and the DPIA process is complete.  Return the form to the IGU.

4.		Will the project involve large-scale processing? 
There is no definition of large-scale but you should consider:
-	the number of individuals involved;
-	the volume of data
-	the duration of the processing; and

More information can be found on the ICO’s website.
